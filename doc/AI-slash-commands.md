# TypoDev স্ল্যাশ কমান্ড

## ব্যবহার

1. চ্যাট বা টেক্সট বক্সের নতুন লাইনের শুরুতে `/` লিখুন। সাজেশন বারে ছয়টি কমান্ড পাবেন; অনুভূমিকভাবে স্ক্রল করে সবগুলো দেখা যায়। `/re` লিখলে মিল থাকা কমান্ডগুলো দেখাবে।
2. চিপে ট্যাপ করে নাম পূরণ করুন, অথবা নিজে লিখুন। নামের পরে স্পেস দিয়ে একই লাইনে আপনার লেখা বা বিষয় দিন। উদাহরণ: `/rewrite আমি আপনার পণ্য সম্পর্কে জানতে চাই`।
3. **Generate** চিপ বা কিবোর্ডের Enter/Send চাপুন। এটি কমান্ড চালাবে; চ্যাটে মেসেজ পাঠাবে না। শুধু কমান্ডের নাম লিখলে AI চালু হবে না—আগে টেক্সট দিতে হবে।
4. ফলের প্রিভিউ পড়ুন। ফলের লেখায় ট্যাপ করলে কমান্ডের জায়গায় ফল বসবে। লং প্রেসে কপি, রিফ্রেশে আবার জেনারেট, Back-এ বাতিল করে কিবোর্ডে ফেরা যায়।
5. `/remember আগামীকাল সকাল ১০টায় মিটিং` লিখে **Save** বা Enter চাপলে তথ্য এই ডিভাইসে সেভ হবে। `/remember`-এর পাশে **Saved notes** থেকে পড়া, কপি, আলাদা নোট মুছে ফেলা ও সব মুছে ফেলা যায়। এটি নোট সংরক্ষণ করে; নির্দিষ্ট সময়ে অ্যালার্ম বা নোটিফিকেশন দেয় না।

## বাস্তবায়ন ধাপে ধাপে

1. **চেনা ও পার্স করা:** `SlashCommand` বর্তমান লাইনের শুরুর `/` এবং ইংরেজি কমান্ডের নাম পড়ে। আংশিক নাম থেকে মিল থাকা চিপ তৈরি হয়। URL, ফাইল-পাথ, অজানা কমান্ড ও সাধারণ লেখার মাঝখানের স্ল্যাশ কমান্ড নয়। সর্বোচ্চ 4096 অক্ষর; কার্সর লাইনের শেষে থাকতে হবে।
2. **এডিটরের সংযোগ:** `SlashCommandEditor` Android `InputConnection` থেকে কার্সরের আগের/পরের লেখা এবং সিলেকশন পড়ে। শুধু সাধারণ টেক্সট ফিল্ডে কাজ করে; পাসওয়ার্ডে বন্ধ থাকে। ব্যাচ এডিটে শুধু কমান্ডের অংশ পরিবর্তন হয়। এডিটর কমান্ডের লেখা পড়ার অনুমতি না দিলে সাজেশন পাওয়া যাবে না।
3. **সাজেশন UI:** `keyboard.xml`-এর `slash_commands_scroll` এবং `CandidatesView` বিদ্যমান সাজেশন বারে থিম অনুযায়ী চিপ দেখায়। টাইপ করা নাম অনুযায়ী তালিকা ছোট হয়। × দিয়ে তালিকা লুকানো যায়; লেখাটি সাধারণ টেক্সট হিসেবেও রাখা যায়। মাইক ও ম্যাজিক বাটনের পুরোনো সুবিধাগুলো একই থাকে। শব্দের সাজেশন বন্ধ থাকলেও স্ল্যাশ চিপ দেখানো হয়।
4. **নির্বাচন ও চালানো:** `Keyboard2` কমান্ড পূরণ ও রান পরিচালনা করে। `KeyEventHandler` কমান্ডের নাম Avro দিয়ে বাংলা করা বা স্পেসে অটোকারেক্ট হওয়া আটকায়। কমান্ডের পরে সাধারণ বাংলা/ইংরেজি টাইপিং চলে। শুধু ট্যাপ বা Enter/Send-এ কাজ শুরু হয়; টাইপ করার সময় API কল হয় না।
5. **প্রম্পট:** `SlashCommand`-এ প্রতিটি কাজের স্থির নির্দেশনা আছে। `/rewrite` অর্থ রেখে প্রাঞ্জল ইংরেজি, `/reply` উৎসের ভাষায় ভদ্র উত্তর, `/email` Subject ও body, `/code` চাওয়া ভাষা অথবা Java এবং `/explain` ব্যাখ্যা/সম্ভাব্য কারণ/সমাধান তৈরি করে। প্রম্পট অজানা তথ্য বানানো নিষেধ করে। কমান্ডের পরের লেখা আলাদা user input হিসেবে বর্তমান `AiProvider`-এ যায়। Gemini ও OpenAI-compatible provider-এর বিদ্যমান সেটিং ব্যবহার হয়।
6. **ফল ও Insert:** `AiWritingResultsView.Task.COMMAND` একটি সম্পূর্ণ ফল দেখায়। ইমেইল, কোড ব্লক ও লাইন-ব্রেক তিনটি ছোট সাজেশনে ভাগ করা হয় না। Insert-এর আগে আগের এডিটর, ইনপুট সেশন, কার্সরের আশেপাশের লেখা ও সিলেকশন মিলিয়ে দেখা হয়। এরপর শুধু `/command ...` মুছে `commitText()` দিয়ে ফল বসে; আগের ও পরের মেসেজ রাখা হয়। ব্যর্থ API কল বা প্রিভিউ বন্ধ করলে মূল লেখা থাকে।
7. **লোকাল নোট:** `SavedNoteStore` শুধু ব্যবহারকারীর Save অ্যাকশনে ব্যক্তিগত SharedPreferences-এ নোট লেখে। `/remember` AI-তে পাঠানো হয় না। সর্বোচ্চ ৫০ নোট; পূর্ণ হলে পুরোনো নোট নিঃশব্দে বাদ না দিয়ে ত্রুটি দেখায়। একই লেখা আবার সেভ করলে নতুন নোট তৈরি না করে তালিকার সামনে আসে। অ্যাপের Android backup বন্ধ আছে।

## যাচাই

সংশ্লিষ্ট ৬৭টি ইউনিট টেস্ট পাস করেছে। পার্সিং, প্রিফিক্স, সাধারণ স্ল্যাশ, পাসওয়ার্ড ফিল্ড, কমান্ড পূরণ, এডিটর পরিবর্তনের পরে লেখা না মোছা, Avro নাম সংরক্ষণ, Enter রাউটিং, বহুলাইন ফল এবং লোকাল নোটের স্থায়িত্ব/ডিলিট/সীমা পরীক্ষা করা হয়েছে। Debug ও Release বিল্ড সফল; lint-এ ০ error, অন্য ভাষার অনুবাদসহ warning আছে।

Android এমুলেটরে `/` ও `/re` চিপ, ট্যাপ করে নাম পূরণ, Save, hardware Enter ও keyboard Enter দিয়ে নোট সেভ, Saved notes থেকে পড়া/ডিলিট, API key না থাকলে Configure অপশন এবং পুরোনো ম্যাজিক মেনু যাচাই করা হয়েছে। Hardware Enter-এর down/up দুটো ইভেন্টই কমান্ড চালানোর সময় আটকে রাখা হয়, যাতে মূল টেক্সট বক্সে পরের key-up না পৌঁছায়।

AI-এর পাঁচটি কমান্ড চালাতে ব্যবহারকারীর নির্বাচিত provider-এর API key প্রয়োজন; নোট সেভে key লাগে না। এমুলেটরে API key ছিল না, তাই আসল provider-এর response সরাসরি জেনারেট করে যাচাই করা হয়নি। প্রম্পট ও ফলের ফরম্যাট/Insert-এর আচরণ ইউনিট টেস্টে যাচাই করা হয়েছে।

Android ভিত্তি: [InputConnection](https://developer.android.com/reference/android/view/inputmethod/InputConnection), [Creating an input method](https://developer.android.com/develop/ui/views/touch-and-input/creating-input-method)।
