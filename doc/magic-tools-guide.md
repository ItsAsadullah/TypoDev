# Magic Tools quick guide / ম্যাজিক টুল গাইড

**Text from image / ছবি থেকে লেখা:** Open the Magic menu, choose **Text from image**, then **Take photo** or **Choose from gallery**. Gemini reads the selected image and copies readable text to the clipboard. Review or edit the preview and tap **Copy text** again if needed. Internet and a Gemini API key are required. If no text is found, your existing clipboard stays unchanged. Camera photos are temporary and removed when this screen closes.

ম্যাজিক মেনু → **ছবি থেকে লেখা** → **ছবি তুলুন** অথবা **গ্যালারি থেকে নিন**। লেখা পাওয়া গেলে কপি হবে; প্রিভিউতে সংশোধন করে আবার কপি করা যায়। এই অপশনে ইন্টারনেট ও Gemini API key প্রয়োজন।

The walkthrough opens automatically the first time you use the magic menu. Afterwards, open **Settings → AI Assistant → Magic Tools guide** to see it again. You can also use the settings icon in the magic menu to open Writing Settings and its guide. The guide follows the app language and includes Bengali for Bangladesh.

ম্যাজিক মেনু প্রথমবার খুললে গাইড দেখাবে। পরে **Settings → AI Assistant → ম্যাজিক টুল ব্যবহার গাইড** থেকে আবার দেখতে পারবেন।

1. Open **Writing Settings**, enter a Gemini API key and choose a model. An internet connection is required. Your selected text or image is sent to the provider.
2. Write or select text, then choose **Edit text**. **Proofread** fixes spelling and grammar with minimal changes; **Rephrase** improves wording. Already correct text can return unchanged, and proofreading can show fewer than three options.
3. Copy a message and choose **Reply to copied text**, or select **Choose an image**, **Recent screenshot** or **Capture screen** to draft a reply from an image. Check the selected image. Capture requires Android permission.
4. Start a sentence and choose **Continue writing** for new text to append.
5. Compare options with **Previous** and **Next**. Tap **Insert** or the result to insert, hold the result to copy, or choose **Try again** for new options. Return to the keyboard to cancel.

Screen capture gives you a three-second countdown. Keep the desired post visible. After a successful capture, the approved screen-sharing session remains active for repeat captures. The ongoing notification has **Stop capture**; five minutes of inactivity also stops the session. Android requires permission again for a new session, including after locking the phone or stopping screen sharing. Frames are only converted and delivered for an explicit capture request.

Example: `I has a meeting tomorrow.` → **Edit text → Proofread** → `I have a meeting tomorrow.`

After returning to the keyboard, open the magic menu and choose **Return to last generated text** to recover the latest successful results, selected option and style without generating again. If the original text field has changed, hold the result to copy it. The latest draft stays in memory while the keyboard service runs; it is replaced by newer successful results and is cleared when the service stops.

ব্যাক করার পরে ম্যাজিক মেনু → **আগের তৈরি করা লেখা দেখুন** চাপলে শেষ তৈরি করা ফল ফিরে পাবেন। লেখার জায়গা বদলে গেলে চেপে ধরে কপি করতে পারবেন। কিবোর্ড সার্ভিস চালু থাকা পর্যন্ত শেষ ফল মেমোরিতে থাকে; সার্ভিস বন্ধ হলে মুছে যায়।

প্রথমে সেটিংসে API key ও মডেল দিন। লেখা সংশোধনে **Edit text**, কপি করা মেসেজের উত্তরে **Reply to copied text**, আর অসমাপ্ত বাক্যের জন্য **Continue writing** ব্যবহার করুন। ফল দেখে **Insert** চাপুন, অথবা চেপে ধরে কপি করুন।

Provide the relevant context and clear images. Review names, dates, numbers and meaning before sending: AI can make mistakes. If generation fails, check the connection and API key, then retry.

ভালো ফল পেতে প্রয়োজনীয় প্রসঙ্গ দিন ও পরিষ্কার ছবি ব্যবহার করুন। পাঠানোর আগে নাম, তারিখ, সংখ্যা ও অর্থ যাচাই করুন। অনুরোধ ব্যর্থ হলে ইন্টারনেট ও API key দেখে আবার চেষ্টা করুন।
